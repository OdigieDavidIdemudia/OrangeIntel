# OrangeIntel

An application for creating and managing threat advisories and assessments in a more streamlined workflow.

## Purpose
This repository is intended to host the app logic, supporting documentation, and deployment assets for OrangeIntel.

## Recommended structure
- `src/` — business logic and app source
- `tests/` — automated tests
- `docs/` — architecture and setup docs
- `assets/` — design or media files
- `config/` — app configuration and settings

## Getting started
1. Clone the repository.
2. Restore NuGet dependencies.
3. Copy any sample app settings into a local config file.
4. Run the application in development mode.

## Project hygiene
- Keep secrets out of source control.
- Keep configuration explicit and environment-driven.
- Use a clear folder structure to support long-term maintainability.

## Status
This repository has been organized with a standard baseline for maintainable software development.
